# เภสัชกรรมไทย: ศาสตร์การชั่งตวงวัด & วิธีปรุงยา 28 ขนาน

คู่มือการเรียนรู้แบบ interactive สำหรับวิชาเภสัชกรรมไทย — ว่าด้วยการชั่ง ตวง วัด (พิกัดน้ำหนัก/ขนาด) และวิธีปรุงยาแผนโบราณ 28 ขนาน

- ไฟล์หลัก: `index.html` (เปิดได้โดยตรงในเบราว์เซอร์ ไม่ต้องติดตั้งอะไร)
- เนื้อหาอ้างอิงตามตำราเภสัชกรรมไทยแผนโบราณ
